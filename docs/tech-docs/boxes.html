boxes

deploy start twelve programs on one computer. each one has one job. these are the boxes.

the front door

your browser talks to one box: frontend. it is caddy, a web server. it hands the pages out. it passes everything else on by path.

every box

boxjobremembers
frontendthe front door. serves the pages. sends each path to its box. http → https.nothing
pagesbuilds the react pages into a folder. hands it to frontend. quits.the built pages
certsmakes the https cert for your ip. quits. runs again only if the ip changed.the cert
apisave a status, an about me, a picture. go live. stop. the log of starts and stops. the watch page's html so links get a preview card. /api/health, /api/errors.nothing itself
chatthe text chat. one socket per viewer. same program as api, run as api chat. see chat.nothing itself
eventsthe data wire. one socket per browser, on every page. who is here, who went live, who ended. run as api events.nothing. a restart: browsers come back in 3 s, it replays the last 10 s
homethe home list. every live stream and how many watch it. in memory. checked against video every 30 s. run as api home.in memory only
databasepostgres. the accounts, the status, the about me, the log, follows, messages, the inbox. not the video. a second database, debug, for the pages' error reports.everything that must last
redisfast memory. who is live now. who is here now. the chat's last 500 lines a room. the stream of facts the pushes come from.until it restarts. no save file
s3a bucket on this computer (seaweedfs). profile pictures, banners, thumbnails. S3_ENDPOINT=off uses it. a url uses a real bucket instead.the pictures
videorust. one upload in, copies out. a jpeg of every live stream every 5 s. room for about 25 streams.nothing
dummyfake streams. gifs bouncing around with a name on top. off unless DUMMY_STREAMS says a number.nothing

small rules

  • every box logs to 3 files of 10 MB. then the oldest goes. a box left alone never fills the disk.
  • only three ports open: 80, 443, 7882/udp. database and redis have no door to the outside.
  • peek inside: docker compose exec database psql -U stream. docker compose exec redis redis-cli.
  • chat, events and home are the api program with a different first word. one image, no extra build.
  • a deploy of video ends every stream. a deploy of anything else does not.
