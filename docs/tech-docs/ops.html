the box

every run is a release. numbered one past the last. v12. tagged on the commit once all four images are up. /api/health says which one runs. --images v12 pins one.

a commit that only touched docs has no images of its own. it runs the ones before it. nothing restarts for it.

what broke for a person

a page breaks. it tells on itself. POST /api/errors, to its own site, with the commit it was built from.

the api keeps the reports in a second database, debug. the main one is never touched. the api runs fine without it.

/admin shows them. for the names in ADMIN_NAMES. a machine reads them with OPS_TOKEN instead. 16 letters at least, or it is ignored.

what is the browser being told

the messages inspector. advanced tab of the user modal. it keeps the frames this browser sends and gets on its three sockets. the last 1000. a filter. a panel over the page.

tokens are taken out first. nothing leaves the browser.

the knobs

.env in the repo root. .env.example explains every line. a pull brings new knobs in with their defaults. a line you set is never touched.

knobwhat
PUBLIC_IPthe ip people type. deploy fills it in.
ENV_NAMEwhat this box calls itself in health and in errors. empty: the hostname.
ADMIN_NAMESwho may open /admin. empty: nobody.
OPS_TOKENa machine's key for the errors. empty: off.
DUMMY_STREAMS DUMMY_PASSWORD DUMMY_NAMESthe fake streams. how many, the key, your own names.
S3_ENDPOINT and friendsoff: the bucket on this box. a url: a real bucket.
CHAT_PERSIST1: every chat line kept in the database. search and scroll back.
GROUPS_PER_OWNERgroups one login may own. empty: 2. 8 at most.
CARGO_BUILD_JOBScores a rust build may use. deploy sets it from the ram.
IMAGES TAGwhere the images come from and which ran last. deploy writes them.
SHOW_DOCS1: these pages on the dev server. the box ignores it.
