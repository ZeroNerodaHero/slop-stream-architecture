how to read these

  • one page, one topic. short sentences. every number is real.
  • the moving dots are data moving. the arrow says which way.
  • a box is a program or a place. a dashed one remembers things. a dotted one is not built yet.
  • the square next to a name is presence: here, live, do not disturb, off.
  • each page names its long doc at the bottom. the long docs are docs/*.md. they have every rule.
