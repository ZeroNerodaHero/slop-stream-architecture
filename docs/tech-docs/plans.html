a plan is not stale. it is a thing decided but not made. when one is built, it leaves this page and lands on its own.

whole plans

  • posts (posts.md). a login writes a short post. one picture or none. a reply is a post pointing at another. one table. the feed is a read over follows, not a timeline per follower. a post is one fact on the wire, so every follower has it at once.
  • more video sizes (bitrates.md). the streamer keeps sending one 1080p. the box makes 720 and 360 copies. a watcher gets one of them.
  • hover to preview (hover-preview.md). hold the mouse on a card and it plays. click, and the page keeps the connection the card made. the first frame is instant.
  • kubernetes (kubernetes.md). what it would buy. the video routing problem. the code to change first. the steps.
  • metrics (metrics.md). cpu, memory, disk, network. per box, per container. our own code: an api agent on every box, the monitor drawing it, alerts on the lines that matter.
  • the move off polling (transition.md). every http loop the pages ran, which became pushes, what stays http, the deploy order with a way back.
  • the product (idea.md). open groups where people show their face and talk. a stream you decorate. one person's audio for everyone else.

second halves

built, but not all of it.

  • audio (audio.md). built: the mixer, and mic only. plan: home's card for a mic only stream. a tab's sound. up to 4 people on the watch page coming on with a mic, or a mic and a camera.
  • calendar (calendar.md). built: the tab, the blocks, the week strip. plan: the totals on the profile tab. a schedule.
  • follows (follows.md). built: the edge, the column, the button, the counts. plan: followed streams first on home. the modal tab.
  • debugging (debugging.md). built: health, the reports, /admin, the monitor program. plan: the monitor box itself. a watcher bot. grafana.
  • about (about.md). built: the about me, the page of blocks, its editor, the css rules. plan: @keyframes in their css. themes to pick from, the way myspace had layouts.
long version: docs/README.md says which doc is a plan. each one above is in docs/.
